# Apartment scan data

Written by the [Apartments workflow](https://github.com/rohit9mehta/personal-site/actions/workflows/apartments.yml) on `main`; don't edit by hand.

`scan.json` holds the listings that arrived in StreetEasy saved-search alerts, and for each building its location and
pest records from NYC Open Data. The apartments page on the site reads it straight from this branch.

Each scan is one commit, so this branch's history is the hunt's history. It never merges into `main`.
